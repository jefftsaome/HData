## 命名规范(2026-08-05 起)

- **活文档**(持续维护)：文件名**不带日期**，头部标注 `> 状态:持续更新`。结构/接口/流程变化时修订。
- **结论文档**(带时间性)：文件名带日期后缀 `-YYYYMMDD`，头部标注 `> 结论截至:YYYY-MM-DD`。
  逆向结论有保质期——平台更新后按日期判断该结论是否还适用。
